# Schedule Cruz Solutions

App interno da Cruz Solutions Services Corporation para montar a escala diária das equipes e gerar a mensagem do WhatsApp.

**Abrir o app:** https://cruzsolutionsapp.github.io/cruz-schedule/

## Instalar no aparelho
- **iPhone / iPad:** abra o link no Safari → botão Compartilhar → **Adicionar à Tela de Início**.
- **Android:** abra no Chrome → menu ⋮ → **Instalar app**.
- **Computador:** abra no Chrome ou Edge → ícone de instalar na barra de endereço.

## Acesso
- O administrador libera o e-mail da pessoa em **Cadastro → Acesso**.
- A pessoa abre o app, toca em **Primeiro acesso**, cria a senha e confirma o e-mail.
